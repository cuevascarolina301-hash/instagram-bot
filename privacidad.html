Política de privacidad – Carolina Shorts

Última actualización: 21 de octubre de 2026

Qué es Carolina Shorts

Carolina Shorts es una herramienta privada que usa únicamente la autora Carolina Cuevas para publicar sus propios vídeos cortos en su propio canal de YouTube (@carolina.cuevas.libros). No es un servicio abierto al público y ninguna otra persona puede conectarse a ella.

Datos a los que accede

La herramienta usa los Servicios de API de YouTube con el permiso youtube.upload, exclusivamente para subir vídeos al canal de la autora y fijar su título, descripción y fecha de publicación. No lee, no recopila y no almacena datos de otros usuarios de YouTube, ni datos personales de nadie.

Almacenamiento y seguridad

La clave de acceso de la autora se guarda cifrada como secreto de GitHub Actions y solo la utiliza el proceso automático de publicación. No se comparte, no se vende y no se transmite a terceros.

Revocar el acceso

El acceso puede revocarse en cualquier momento desde la página de permisos de seguridad de Google: https://myaccount.google.com/permissions.

Servicios de YouTube y Google

Esta herramienta usa los Servicios de API de YouTube. Al usarla se aplican los Términos de servicio de YouTube y la Política de privacidad de Google. El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.
